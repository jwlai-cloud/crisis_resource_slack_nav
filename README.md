# crisis_resource_slack_nav
A Slack agent that turns a disaster-struck community's chaotic group chat into a coordinated relief operation — matching needs to local offers via Real-Time Search and to official resources via MCP, with a human always in the loop.

Built for the Slack Agent Builder Challenge ("Slack Agent for Good" track). Design, scope, and conventions live in [`CLAUDE.md`](CLAUDE.md); the source of truth for architecture and the build plan is [`crisis_resource_navigator_design_doc.md`](crisis_resource_navigator_design_doc.md).
